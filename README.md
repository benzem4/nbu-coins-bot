# 🪙 NBU Coins Tracker Bot

Telegram бот для моніторингу нових монет НБУ України.

## 📋 Опис

Бот автоматично перевіряє каталог монет НБУ двічі на день (о 9:00 та 22:00) і сповіщає підписників про:
- Нові монети в каталозі
- Монети що надійшли у продаж
- Зміни статусів монет

## ✨ Функції

- 🔍 **Автоматична перевірка** двічі на день
- 🎹 **Зручна клавіатура** з кнопками
- 🎨 **Розрізнення статусів:**
  - 🟢 У продажу (можна замовити)
  - 🔜 Скоро у продажу (анонсовано)
  - ⏳ Очікується (ще не надійшло)
- 🔗 **Прямі посилання** на монети та замовлення
- 📊 **Статистика** моніторингу

## 🚀 Налаштування на Render.com

### 1. Створення бота в Telegram

1. Знайди [@BotFather](https://t.me/BotFather) в Telegram
2. Відправ `/newbot`
3. Дай боту ім'я та username
4. Збережи отриманий токен

### 2. Підготовка GitHub репозиторію

1. Створи новий репозиторій на GitHub
2. Завантаж файли:
   - `nbu_bot.py`
   - `requirements.txt`
   - `.gitignore`
   - `README.md`

### 3. Деплой на Render

1. Зайди на [render.com](https://render.com)
2. **New Web Service** → підключи GitHub репозиторій
3. Налаштування:
   - **Name:** `nbu-coins-bot`
   - **Region:** `Frankfurt (EU Central)`
   - **Runtime:** `Python 3.11.9`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python nbu_bot.py`
4. **Environment Variables:**
   - Додай змінну `TELEGRAM_TOKEN` = твій токен від BotFather
5. **Create Web Service**

### 4. Перевірка

1. Дочекайся завершення deploy (~5 хвилин)
2. Відкрий Logs - має з'явитися:
   ```
   ✅ Токен валідний! Бот: @твій_бот
   🤖 Бот запущено!
   ✅ Розклад налаштовано: перевірка о 9:00 та о 22:00
   ```
3. Знайди бота в Telegram і надішли `/start`

## 🎮 Команди бота

### Кнопки:
- 🔍 **Перевірити зараз** - перевірка каталогу
- 📋 **Список монет** - показати всі монети
- 📊 **Статус бота** - інформація про бота
- 🛑 **Відписатися** - відписатися від сповіщень

### Команди (альтернатива кнопкам):
- `/start` - підписатися на сповіщення
- `/check` - перевірити каталог зараз
- `/list` - показати всі монети
- `/status` - статус бота
- `/stop` - відписатися

## 🔧 Налаштування часового поясу

За замовчуванням Render використовує UTC. Для коректного часу:
- 9:00 київського часу = 7:00 UTC (зима) або 6:00 UTC (літо)
- 22:00 київського часу = 20:00 UTC (зима) або 19:00 UTC (літо)

Час в коді вказано як `09:00` та `22:00` - це UTC час, який потрібно відкоригувати залежно від сезону.

## 🆘 Вирішення проблем

### Бот не реагує на команди
1. Перевір логи на Render - чи запустився бот?
2. Переконайся що використовуєш правильного бота (перевір username)
3. Спробуй відправити `/start` замість кнопок

### "Conflict: terminated by other getUpdates"
1. На Render: Settings → Suspend
2. Почекай 60 секунд
3. Settings → Resume
4. Або: Manual Deploy → Clear build cache & deploy

### Бот не знаходить монети
1. Перевір логи - має бути "Знайдено унікальних продуктів: X"
2. Якщо 0 - сайт НБУ змінив структуру, потрібно оновити парсер
3. Перевір вручну https://coins.bank.gov.ua/catalog.html
